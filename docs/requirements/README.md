## 全局业务角色

- **访客**：未注册用户，仅可看到登录/注册入口。
- **普通用户**：可以完善资料、浏览同社区主题、发布主题、接收主题推送、接受参与、聊天和评价。
- **系统任务**：执行主题推送、统计评价、计算风险标签等异步工作。
- **运营/管理员**：维护社区和评价分类，处理封禁、申诉和异常数据（概览未明确后台界面，本文仅定义业务能力）。

## 全局状态约定

- 任何涉及状态变更的操作必须服务端校验权限和当前状态，客户端不能仅凭按钮状态判断是否可操作。
- 重复提交应返回幂等结果，不得创建重复推送收件记录、参与关系、聊天室、消息或评价。
- 业务失败需给出可展示的错误原因；技术错误不向客户端暴露堆栈或敏感信息。
