## 关键业务规则

1. 用户昵称、社区为必填；年龄、性别、头像为可选。
2. 用户注册支持邮箱或短信验证码；验证码只保存不可逆摘要。
3. 用户 7 天内不可切换社区。主题只推送给同社区用户，并且还需满足主题约束。
4. 接受同一主题的用户自动进入该主题聊天室；只有这些用户可以互相评价。
5. 评价分为好、中、差，并支持“守信、失约”等分类；评价及自动评级均保留审计记录。
6. 所有 HTTP 返回均包含 `code`、`message`、`data`、`request_id`。

文档中的 UUID、时间和分页字段均以 API 约定为准；实现时可将 UUID 生成放在应用层或 PostgreSQL `gen_random_uuid()`。
