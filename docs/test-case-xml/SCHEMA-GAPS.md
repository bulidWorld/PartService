# 格式与执行能力缺口

本报告以工作区现存 `task.xsd` 为准，见 [规范来源说明](README.md)。具体用例覆盖和 HTTP 前提限制以 `notes/NNN.md` 为准。此处区分 XML 无法表达与业务接口无法支持两类问题，未修改 XSD。

| 类别 | 无法表达的要求 | 影响与记录 |
| --- | --- | --- |
| 动态负向 JSON | 结构化 body 按 OpenAPI 强校验；rawBody 虽可保留非法字段或缺字段，但禁止参数引用及插值 | 缺 nickname、超长 nickname 且社区 ID 必须取前序 HTTP 时，无法合法构造请求；[TC-009](notes/009.md)、[TC-014](notes/014.md) 明确阻塞，不发送固定或伪造社区 ID |
| 跨任务控制 | 单个 XML 不声明共享身份互斥锁、任务组停止策略、清理失败后的环境禁用 | 共享邮箱/手机号串行、任何账号清理失败即停止后续用例需执行器编排；finally 只能保障本任务清理尝试 |
| 运行报告 | 没有将真实 HTTP 状态、请求开始/结束时刻、完整清理终态直接提取到全局参数的通用接口 | 可断言 HTTP 状态并提取业务码/requestId；脱敏执行记录、清理确认和环境污染结论需执行器提供 |
| 动态条件与状态赋值 | 条件只支持参数与固定 JSON 值比较；compute 是受限日期/数值表达式，不能执行任意参数比较或布尔逻辑后赋值 | 异常成功注册的用户 ID 去重、异常登录响应的用户归属比对后选择清理凭证等无法完全编码；见 [TC-016](notes/016.md)、[TC-019](notes/019.md) |
| 请求时限与轮询 | 无“必须在前一响应后 N 秒内发起”的截止限制，无一般轮询/重试循环 | 冷却窗口用例可相邻发送并真实等待，但无法在 XML 内证明请求确在窗口内；见 [TC-006](notes/006.md) |
| 动态完整年龄整数 | 受限 compute 没有年份提取、字符串到整数转换、日期差或生日比较；`format_date` 只能返回 string | 源用例要求固定生日按执行日 UTC 计算整数年龄，不能写死当年年龄，也不能把字符串当整数绑定；见 [TC-045](notes/045.md) |

## 2026-10-23 批次（TC-093 ~ TC-142）新增记录

新增格式无法表达项（XSD 未修改，均已记入对应 notes）：

| 类别 | 无法表达的要求 | 影响与记录 |
| --- | --- | --- |
| 源用例元数据 | 模块/优先级/执行条件/执行记录表没有 XML 元素 | 由 task name 与 notes/NNN.md 承载，执行记录由执行方填写 |
| 轮询与重试 | 无轮询/重试循环节点 | 「等待异步重算后轮询摘要」只能以固定 wait 近似，SLA 时效无法在 XML 内证明；见 [TC-116](notes/116.md) |
| rawBody 不可插值 | rawBody 不解析、不插值，动态字段无法进入非法 JSON 体 | 超长备注负向用例以固定载体主题回显超长字符串，目标字段用参数引用绕过；见 [TC-112](notes/112.md) |
| 静态契约盘点 | 「检查已发布 API 是否有某入口」没有对应 HTTP 操作 | 由离线 validate.py 路径校验保证，XML 末步 Blocked 说明；见 [TC-121](notes/121.md) |

本批次新增业务接口缺口：

- **邀请域接口整体下线**：`invitations.yaml` 已删除，`POST /topics/{topicId}/invite`、`POST /invitations/{invitationId}/accept`、`POST /invitations/{invitationId}/reject` 不再存在；现行契约改为 `POST /topics/{topicId}/accept` 回执模型（另有 `GET /topics/receipts`、`POST /topics/{topicId}/read`）。按旧邀请流程编写的文件（含既有 003~092 与本批次）在当前 OpenAPI 下全量校验报「matched 0 operations」，需在接口重构稳定后统一迁移，或恢复邀请接口兼容层。
- 无公开 HTTP 接口可观察的目标：服务重启（TC-140）、审计日志（TC-139）、风险评级查询/重算/时间窗口/算法版本/标签移除/他人评级可见（TC-122~129）、已读位置查询（TC-093/097）、停用评价分类（TC-114）、评价申诉（TC-121）、账号存在性查询（TC-136）、附件可信域规则（TC-100）、主题历史参与关系（TC-098）。
- `GET /me/rating-summary` 当前实现返回固定零值样例，计数/比率断言无法通过（TC-108/116/119 按阻塞记录）。

以下属于业务接口或规则缺口，扩展 XSD 本身不能补齐：

- `GET /communities` 当前实现固定空列表，无公开创建社区接口；依赖社区的流程先查询并明确阻塞，仍在可表达范围保留后续步骤。
- 无按身份查询账号存在性、验证码投递、用户总数、审计日志、数据库状态等公开 HTTP 查询，不能据拒绝响应声称内部副作用已验证。
- 附件可信域、类型、大小等规则未确认的场景，保留源用例的待确认状态。
- 自然等待可以编码；修改系统时钟、直接造数、数据库查询、日志读取和后台运维不作为替代测试步骤。

离线通过意味着文件符合所校验的格式、接口请求及配置约束，不意味着目标业务已通过。需要补齐业务前提或格式能力的用例不会因前提查询成功而被记作目标场景成功。
