# TC-062 转换说明

- 源文件：`docs/test-case/062-invite-other-community.md`。独立查询社区，A/B 分别注册到不同社区，A 创建主题并邀请 B，检查 HTTP 400/code=40001；B 的 pending 收件列表须为空，并检查 hasMore=false、nextCursor=null。
- 公开 HTTP 无社区创建接口；社区不足或准备请求/凭证失败时 Blocked。当前提取器仅支持固定数组下标，绑定社区前两项并断言 ID 非空且不同；前两项重复/缺失时明确 Blocked，即使后续可能存在其他社区也不冒充覆盖成功。
- 隐私断言要求错误 data 为 null 或空对象、仅含标准响应信封字段，message 不包含本例已知 B 的用户 ID、社区 ID、手机号和昵称。源文档未定义隐私字段完整集合及错误 message 精确格式，以上仅覆盖可观察的已知目标信息，不能证明任意未知隐私或侧信道均无泄露。OpenAPI 未详列邀请 400 错误结构，HTTP 状态及业务码遵循源用例显式断言；无缺失业务接口。
- 注册响应立即提取 user.id、accessToken、refreshToken 及原始令牌；断言失败仍发布，已创建账号进入 finally。按 B、A 清理：GET /me 探测，过期则刷新并更新当前清理凭证，DELETE /me 验证 200/code=0/data={} 和 requestId，再核查原始及最新访问/刷新令牌全部返回 401/code=40101。单步失败仍继续其他清理。
- XSD 无跨任务停止调度能力；任一注销或失效核查失败/未确认，执行者须停止共享环境后续任务，不得将 401 当作注销成功。执行器保留各 REST 状态、业务码、requestId 和结论；令牌敏感参数脱敏。共享邮箱/手机号须串行复用。
- 指定 Python 离线校验：`validate.py` 为 1 XML/0 errors；`validate_importer.py --importer-root /opt/apps/Deployment/AutoTestService` 为 1 XML/0 errors，真实导入器转换和配置校验通过。
- 仅生成及离线校验，未运行 HTTP、未部署、未改数据库；执行记录仍为未执行。
