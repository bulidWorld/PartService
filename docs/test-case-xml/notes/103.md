# 用例 103 生成说明
- 非法 JSON 请求体用 rawBody 保存原文 {"title":（不解析、不插值），Content-Type 仍显式声明 application/json
- 路径负例 not-a-uuid 用 rawPath（path 属性保持 OpenAPI 路径键 /topics/{topicId}，rawPath 与 pathParams 互斥）
- “不暴露堆栈”通过断言 message 不含 Exception/java./at com. 特征来检查（沙箱无 re，只能字符串包含判断）
- 昵称按 md 规则“测+UUID 前 12 位”需要 substring → 固定昵称“测103甲”
- 验证码 code 固定 "123456"（环境已关闭注册验证码校验）
- 本用例未创建业务数据，finally 仅注销 A
- 服务侧实现缺口：ApiExceptionHandler 仅映射 ApiException/NoResourceFoundException，反序列化错误（HttpMessageNotReadableException）与路径 UUID 转换失败（MethodArgumentTypeMismatchException）落入通用 500/50000（message“服务暂时不可用”）；md 期望 400/40001 → 本用例按 md 期望行为编写，服务补齐异常映射前运行将失败（响应体不含堆栈，未泄露内部信息）
