# 用例 075 生成说明

- 六位随机数字验证码：compute 无随机数字函数，code 固定为 "123456"（测试环境已关闭邮箱验证码校验，见 md 执行约定）。
- 昵称 "测+UUID去连字符前12位"：无 substring 函数，改为固定昵称 测075甲/测075乙（昵称允许重复）。
- 收件查询 "每秒重试最多 30 秒"：GET /topics/receipts 使用 poll maxAttempts="30" intervalMilliseconds="1000" timeoutSeconds="30"。
- 清理中 "GET /rooms 按主题 ID 筛选补录 roomId"：extract 表达式不支持按谓词筛选列表元素，无法表达；改为 SQL 清理步骤以 ifParameter="r" 跳过保护，accept 失败未取得 roomId 时聊天室可能残留（不会误删其它用例房间）。
- 保留行为断言：全部账号注销后无有效令牌，无法 HTTP 断言，故放在注销 B（成员）之后、注销 A（发布者）之前，用 A 令牌断言房间保留（topicId=T）、B 已从 members 移除、消息 M 仍可读且 recalled=true 持久保留。
- SQL 表名已按 src/main/resources/db/03-chat.xml 核实：chat_room（外键级联删除 chat_message/chat_message_read/chat_member）。
