# 用例 031 生成说明

- 昵称：md 要求"测+UUID 去连字符前 12 位"，compute 无 substring/去连字符截取能力 → 改为固定昵称（每个角色一个，昵称允许重复）。
- 验证码 code：compute 无随机数字函数 → 固定 "123456"（测试环境已关闭邮箱验证码校验）。
- 断言沙箱禁止 re，社区条目 id 的 UUID 格式只断言非空（与 002 样例同风格）。
- 发布成功断言按 md 检查 publisherId=A.id、communityId=C1、status=open；主题流按本例 ID 筛选"恰好一项 id=T"。
- 收件断言：status=pending 列表中恰好一条 topicId=T，且该条 roomId 与 readAt 均为 null（Schema 中二者 nullable）。
- 聊天室断言：GET /rooms 按 topicId=T 筛选条目数为 0（首次接受前不建房）。
- 清理：本例不创建主题/聊天室（或失败发布不建房），md 清理第 1/5 步"无聊天室则跳过"，故省略 GET /rooms 补录与 chat_room 的 SQL 清理。
