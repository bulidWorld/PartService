# 用例 076 生成说明

- 六位随机数字验证码：compute 无随机数字函数，code 固定为 "123456"（测试环境已关闭邮箱验证码校验，见 md 执行约定）。
- 昵称 "测+UUID去连字符前12位"：无 substring 函数，改为固定昵称 测076甲/测076乙（昵称允许重复）。
- 收件查询 "每秒重试最多 30 秒"：GET /topics/receipts 使用 poll maxAttempts="30" intervalMilliseconds="1000" timeoutSeconds="30"。
- md 步骤 9 的 SELECT 校验 "恰好一行且值=M"：SqlStep 不提取结果，无法断言；SQL 照写执行（SELECT last_read_message_id FROM chat_message_read WHERE room_id=%s AND user_id=%s，绑定 r、b_id），落库校验改为 HTTP 行为验证（两次 POST read 均 200，首次响应 roomId=R、lastReadMessageId=M）。
- SQL 表名已按 src/main/resources/db/03-chat.xml 核实：chat_message_read（room_id/user_id/last_read_message_id 列存在）。
- 清理中 "GET /rooms 按主题 ID 筛选补录 roomId"：extract 表达式不支持按谓词筛选列表元素，无法表达；改为 SQL 清理步骤以 ifParameter="r" 跳过保护，accept 失败未取得 roomId 时聊天室可能残留。
- 保留行为断言：全部账号注销后无有效令牌，无法 HTTP 断言，故放在注销 B（成员）之后、注销 A（发布者）之前，用 A 令牌断言房间保留、B 已从 members 移除、消息 M 仍可读。
