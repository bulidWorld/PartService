# TC-114 转换说明

- 来源：`docs/test-case/114-rating-disabled-category.md`；产物：`114-rating-disabled-category.xml`。源用例结论即为阻塞：GET /rating-categories 只返回启用分类，公开契约没有停用评价分类的 HTTP 接口，无法构造先缓存、再停用、再提交的过程。保留源用例唯一 HTTP 步骤 `GET /rating-categories`（无鉴权、Accept: application/json），核查响应为 HTTP 200/code=0、data 为分类编码字符串数组、requestId 非空后抛出 `Blocked`；查询准备失败同样阻塞，查询成功不代表目标场景通过。
- 未知分类用例（TC-111 已覆盖）不能替代本场景；公开契约无任何停用/管理评价分类接口，未虚构管理接口，不以数据库、日志或内部存储替代断言。
- 阻塞与无法表达项，分两类：
  - 业务接口缺口：六个 rest-api YAML 均无停用评价分类接口（ratings.yaml 仅 `listRatingCategories` 返回启用分类编码数组、`rateTopicParticipant` 及评价查询），客户端缓存的停用分类场景无法构造前提或核查目标。
  - XML 格式无法表达：跨任务「清理失败停止后续任务」由调度器实现，单任务 XSD 无此配置（本场景不创建用户、无清理，不涉及）。
- 清理说明：本场景不注册用户、不写入数据，省略 finally 清理。
- 可表达性结论：XSD/导入器可表达本文件流程（单 GET + raise Blocked 终态）。断言仅使用执行器白名单支持的 `isinstance`、`dict`、`list`、`str`、`all`、`assert` 与 `raise Blocked`。
- 仅生成；未执行 HTTP、部署或数据库操作。XSD/语义及真实导入器离线校验结果见交付简报。
