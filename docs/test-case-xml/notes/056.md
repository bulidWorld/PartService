# TC-056 转换说明

- 来源：`docs/test-case/056-topic-community-snapshot.md`；以实际同编号源文件为准。独立查询双社区、注册同社区 A/B、A 发布主题，读取 communityChangedAt 后真实等待七天加一秒，再分别刷新两用户令牌。
- 切换 A 到社区 B 后检查响应；B 在社区 A 两次读取原主题并断言 communityId 仍为社区 A；A 的 open/20 列表不包含该主题且所有条目属于社区 B。独立空业务环境下要求 hasMore=false，避免首屏遗漏冒充完整隔离验证。
- 社区不足、注册准备失败、等待后刷新失败均明确 Blocked；时间格式由动态 ISO8601 wait 校验，无效时等待节点失败并进入 finally，不能记作通过。
- finally 依次清理 B/A：探测访问令牌、必要时刷新、DELETE /me，检查 200/code=0/data={}/requestId，并逐一核查注册、等待后刷新、清理刷新产生的旧/新访问和刷新令牌均为 401/40101。刷新失败或凭证丢失不能证明账号删除，记录清理失败并停止环境复用。
- XSD 无跨任务停止调度能力；“任何清理失败停止后续用例”必须由任务组调度器落实。进程被终止或等待中服务重启无法保证 finally 执行，应人工核查并停止复用身份。
- HTTP 接口覆盖本用例目标，无需虚构接口或后台操作。仅生成、离线校验，未发送 HTTP、未实际等待、未部署或修改数据库。导入项目 base_url 配置为 http://127.0.0.1:10201/api/v1；共享邮箱/手机号必须串行使用。
- 离线校验：`validate.py`：1 XML、0 errors；`validate_importer.py --importer-root /opt/apps/Deployment/AutoTestService`：1 XML、0 errors。HTTP 实际业务结果尚未执行验证。
