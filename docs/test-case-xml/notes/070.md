# TC-070 转换说明

- 来源：`docs/test-case/070-invitation-reject-retry.md`。独立查询社区、注册 A/B、创建主题与邀请，首次拒绝必须 HTTP 200/code=0、同一邀请/主题/双方 ID、rejected、roomId=null。
- 重复拒绝及随后接受允许 HTTP 200/code=0 且仍为 rejected、roomId=null，或 HTTP 409/code=40901 且有非空 message/requestId（业务冲突码来自 ApiException.conflict）。每次后续查询 B 的 rejected 邀请列表，要求唯一原邀请、无下一页、状态及关联身份不变。最终 B 的聊天室列表必须为空且无下一页。
- 源用例“不生成参与记录”涉及内部 topic_participant 存储，公开契约无独立查询接口或字段，因此此项未直接覆盖，不声称通过；源文档明确排除无法 HTTP 查询的内部存储。聊天室列表断言只证明 B 没有可见聊天室。没有虚构参与记录接口。
- 无社区或注册、主题、邀请准备失败均 Blocked；注册断言失败仍提取 user.id/accessToken/refreshToken，finally 清理本次实际创建的账号，不能删除来源不明的已有身份。所有变量来自本文件前序响应。
- finally 顺序清理 B/A：先 GET /me 探测，40101 时刷新并更新当前访问/刷新凭证；DELETE /me 断言 HTTP 200/code=0/data={} 和非空 requestId，提取业务码及 requestId 用于记录；逐一核查原始及最新访问/刷新凭证 HTTP 401/code=40101。单步失败仍继续其他清理；401 不代表账号已删除。
- XSD/导入器可表达本文件流程。OpenAPI 未声明邀请 409 及 GET /me、refresh 的 401 响应；断言按源允许的明确状态冲突和清理要求验证真实 HTTP/业务码。清理失败跨任务停调度无法由单 XML 表达，调度方须串行使用共享身份，清理失败或未确认立即停止环境复用。记录真实 HTTP/业务码、requestId、清理结论并脱敏，不记录令牌原文。
- 仅生成；未执行 HTTP、部署或数据库操作。XSD/语义及真实导入器离线校验结果见交付简报。
