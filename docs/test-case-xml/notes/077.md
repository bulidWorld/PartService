# TC-077 转换说明

- 来源：`docs/test-case/077-invitations-pagination.md`。独立查询社区，注册 A/B，A 创建三个主题并分别邀请 B，保存 T1/T2/T3、I1/I2/I3；B 以 pending、limit=2 查询首页，提取真实 nextCursor，再查询末页。
- 每个请求显式 auth 和四参数布尔断言；准备失败使用 Blocked。两页均检查 HTTP 200/code=0/requestId、pending 和双方身份及对应主题；首页恰好两条、hasMore=true、游标非空，末页恰好一条、hasMore=false、nextCursor=null。检查每页无重复、两页交集为空且并集精确等于 I1/I2/I3，不假设邀请顺序。
- 注册断言失败仍立即提取 user.id/accessToken/refreshToken 和原始凭证，finally 清理本次实际创建账号；不删除来源不明的账号。无社区时阻塞，公开接口不能创建社区。
- finally 顺序清理 B/A：GET /me 探测访问凭证，40101 时刷新并更新当前访问/刷新凭证；DELETE /me 要求 HTTP 200/code=0/data={}、非空 requestId，并保存业务码/requestId。逐个核查原始及最新访问/刷新令牌 HTTP 401/code=40101；一个清理步骤失败仍继续后续步骤。只有注销成功及核查通过才可确认清理，不能凭 401 推断账号删除。
- 源用例的 HTTP 可观察目标均已表达，无业务未覆盖项。XSD 可表达；OpenAPI 对 GET /me 和 /auth/refresh 未声明 401 响应，按源清理要求检查真实 HTTP 401/code=40101。清理失败后跨任务停止调度无法由单 XML 表达，执行方须串行复用共享身份，任一清理失败或未确认即停止环境复用。执行记录应保留脱敏 HTTP/业务码、requestId 和清理结论，不记录令牌原文。
- 仅生成，未执行 HTTP、部署或数据库操作。已通过 validate.py 的 XSD/语义校验和 validate_importer.py 的真实导入器离线转换/配置校验。
