# 用例 077 生成说明

- 六位随机数字验证码：compute 无随机数字函数，code 固定为 "123456"（测试环境已关闭邮箱验证码校验，见 md 执行约定）。
- 昵称 "测+UUID去连字符前12位"：无 substring 函数，改为固定昵称 测077甲/测077乙（昵称允许重复）。
- 两个主题 T/T2 标题相同（md 原文均为 "测试-${run}"），断言按主题 ID 区分。
- 收件查询 "每秒重试最多 30 秒"：两次 GET /topics/receipts 均使用 poll maxAttempts="30" intervalMilliseconds="1000" timeoutSeconds="30"。
- 跨房间撤回与跨房间已读：md 未给具体业务码（"HTTP 4xx、code 非0"），按规则只断言 400<=statusCode<500 且 code!=0，不臆造业务码。
- 清理中 "GET /rooms 按主题 ID 筛选补录 roomId"：extract 表达式不支持按谓词筛选列表元素，无法表达；改为两个 SQL 清理步骤分别以 ifParameter="r"/ifParameter="r2" 跳过保护，accept 失败未取得 roomId 时对应聊天室可能残留。
- 保留行为断言：全部账号注销后无有效令牌，无法 HTTP 断言，故放在注销 B（成员）之后、注销 A（发布者）之前，用 A 令牌断言房间 R 保留（topicId=T）、B 已从 members 移除、消息 M 仍可读且 recalled=false（跨房间调用未修改原房间消息）。
- SQL 表名已按 src/main/resources/db/03-chat.xml 核实：chat_room（外键级联删除 chat_message/chat_message_read/chat_member）。
