# 用例 022 生成说明

- 伪造令牌 BAD.access_token=generateUUID() 用任务级 function 参数 bad_token 生成；Authorization 头按伪造令牌约定使用 auth mode="header" + 恰好一个显式 Authorization 头，头值由 compute concat("Bearer ", param("bad_token")) 生成参数 bad_auth，header value 写 {bad_auth} 整体引用。
- 五个受保护接口（GET /me、/topics、/topics/receipts、/rooms、/me/rating-summary）均带该伪造 Bearer 令牌，断言 HTTP 401 与业务码 40101。
- 本例无注册步骤，无 finally（md 清理模板均无适用对象）。
- GET /topics 与 GET /topics/receipts 按 md 带 query limit=20（valueType="integer"）。
- 断言沙箱禁用 re：社区每项 id 的 UUID 格式无法断言，仅断言 id/name 非空。
