# TC-022 转换记录

- 来源：`docs/test-case/022-invalid-refresh-token.md`。
- 输出：`022-invalid-refresh-token.xml`，保留唯一的伪造刷新令牌请求；显式不携带鉴权，以 `rawBody` 保留负向输入。
- 判定：HTTP 401、业务码 40101；响应 JSON 中不得出现非空 accessToken / refreshToken，不得返回 Authorization 凭证响应头。
- 本用例不注册、不依赖社区或已有用户，也不创建数据，无需 finally 注销或清理。
- 契约依据：`src/main/resources/rest-api/auth.yaml` 的 POST /auth/refresh、RefreshRequest 和 TokenPair；实现 `AuthControllerImpl.refresh` 对未知令牌抛出 unauthorized，`ApiException` 与 `ApiExceptionHandler` 映射为 HTTP 401 / 40101。
- XSD 缺口：无本用例特有缺口。项目 base_url 由导入项目配置提供，XML 路径使用 /auth/refresh。
- HTTP 接口缺口：无；仅判定 HTTP 可观测响应，不声称核验内部令牌存储。
- 只生成并离线校验，未发送 HTTP，未填写运行通过记录。
