# TC-059 转换说明

- 完整覆盖同社区注册、发布、邀请 pending 字段、B 收件列表恰好一次及接受前无对应房间；列表同时断言无后续分页，避免遗漏。
- 全部 ID、访问令牌及刷新令牌均来自本文件前序 HTTP 响应；注册响应即使断言失败仍提取供 finally 清理。未取得社区或注册前提失败标记 Blocked。
- finally 按 B、A 独立尝试：探测访问令牌，过期则刷新，DELETE /me，逐一核查注册原始及刷新后访问/刷新令牌失效；删除响应保留业务码、requestId，HTTP 状态由步骤记录。
- 未核查内部通知、广播、日志；与源用例范围一致。未发现目标 HTTP 接口缺口。
- XSD 无跨任务停止调度能力；共享身份必须串行，清理失败或未确认时由执行器停止环境复用。401 不能独立证明账号删除；必须同时检查 DELETE 成功和失效核查。
- 仅生成及离线校验，不运行 HTTP、不部署、不修改数据库。base_url 使用 http://127.0.0.1:10201/api/v1（远程环境由导入项目配置）。
