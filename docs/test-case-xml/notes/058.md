# TC-058 转换说明

- 源：`docs/test-case/058-topic-single-age-bound.md`；生成同 stem XML，独立查询社区、邮箱注册、发送仅有 minAge=18 的主题创建请求。未使用其他任务数据。
- 规则阻塞：源明确指出“要求年龄范围完整”与旧 REST 文档“边界均可选”冲突。当前 OpenAPI TopicRequest 也仅要求 title/detail。XML 实际发送请求，记录真实 HTTP 状态（执行器响应记录）、业务码、requestId；HTTP 200/code=0 时检查主题及单侧字段，HTTP 400 时检查非零业务码且没有主题 ID，其他 HTTP 状态判失败。两种候选结果都显式 raise Blocked，不把任一分支、社区查询或准备成功认作目标通过。400 的确切业务码尚未由源及接口契约规定，未虚构 40001。
- 若响应返回主题 ID，即使主断言失败/Blocked 仍提取；finally 在探测及必要刷新凭证后通过 GET /topics/{topicId} 复查保存的标题、详情、发布人、社区、minAge=18、maxAge=null 与空 genders，再继续注销。该查询仅验证可观察字段，不能证明真实年龄筛选或替代产品规则确认；完整目标结论保持 Blocked。
- 注册立即独立提取 USER_A、TOKEN_A、REFRESH_A 和原始令牌，断言失败仍发布并进入清理。finally GET /me 探测过期，必要时刷新并更新凭证，DELETE /me 核对 HTTP 200/code=0/data={}/requestId，逐一核查原始与最新访问/刷新令牌 HTTP 401/code=40101。单步清理失败不阻止后续清理，不能以 401 推断账号已删除。
- XSD 没有阻碍本场景表达的缺口。HTTP 契约没有社区创建接口，无可用社区则 Blocked；400 错误业务码与单侧年龄的最终规则属于未确认范围。没有增造接口或改动源/XSD。
- 单 XML 不能表达跨任务共享身份互斥及清理失败停止调度。执行器须串行复用该邮箱，清理失败/未确认即停止后续任务，保留脱敏 HTTP/业务码、requestId 与结论，不保存令牌原文。
- 仅生成与离线校验，未调用业务 HTTP、部署服务或修改数据库。
- 校验：指定虚拟环境运行 `validate.py`：1 XML files checked; 0 error(s)。运行 `validate_importer.py --importer-root /opt/apps/Deployment/AutoTestService`：1 XML、0 errors。
