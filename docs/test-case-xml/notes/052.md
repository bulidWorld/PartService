# TC-052 转换记录

- 源文件：`docs/test-case/052-topic-forbidden-close.md`；生成 `052-topic-forbidden-close.xml`，仅生成，未执行 HTTP。
- 覆盖独立社区查询、A/B 注册并立即保存用户及原始双令牌、A 创建主题、B 关闭返回 HTTP 403/code=40301、A 详情查询确认完整主题响应内容与创建快照一致且为 open。
- 社区不足、注册或创建准备请求失败明确 Blocked。当前无社区创建 HTTP 接口；不能以前提查询成功代替目标通过。
- finally 依 B、A 顺序 GET /me 探测凭证；过期时刷新并更新清理凭证；逐个 DELETE /me，检查 HTTP 200/code=0/data={}/requestId，再核查原始和最新访问/刷新令牌均 HTTP 401/code=40101。清理某用户失败不阻止另一用户。
- 未覆盖：没有 HTTP 可观察的内部存储/广播/日志；不执行跨任务调度。共享邮箱/手机号必须串行，执行器须记录脱敏实际响应及清理结论，清理失败或未确认时停止后续用例，单 XML 无法表达跨任务停调度。
- XSD/HTTP 缺口：所需路由均存在，XSD 可表达本用例；OpenAPI 未列出关闭接口的 403 响应，XML 按源用例显式断言实际 HTTP 403 和业务码 40301。
