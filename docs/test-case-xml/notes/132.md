# TC-132 转换说明

- 来源：`docs/test-case/132-auth-expired.md`。查询社区、注册邮箱用户 A、真实等待注册响应 expiresIn+1 秒后，过期 accessToken 访问 GET /me 应 HTTP 401/code=40101；随后用有效 refreshToken 刷新并保存新令牌，新令牌 GET /me 应 HTTP 200/code=0 且 id 为 USER_A。
- 步骤 10 社区准备失败或无社区均 Blocked（公开 HTTP 无社区创建接口）。步骤 20 注册按 md 使用邮箱 782213745@qq.com、code=246810、昵称测试用户A；409 身份冲突或非 200 均 Blocked；断言失败仍提取 USER_A/TOKEN_A/REFRESH_A 及原值副本、EXPIRES_IN 供 finally 清理。expiresIn 缺失、非法或超过 2592000 秒（30 天等待上限）时 raise Blocked，对应“等待时长超出上限或不可行按惯例 Blocked”。
- 步骤 30 用动态等待 `<wait parameter="EXPIRES_IN" mode="duration" unit="seconds" offsetMilliseconds="1000"/>` 真实等待 expiresIn+1 秒（远在 30 天上限内），期间不使用、不刷新、不注销任何凭证。
- 步骤 40 目标断言（直接 assert 风格）核对真实 HTTP 状态码 401、业务码 40101、requestId 非空、信封键子集不超过 code/message/data/requestId、data 为 null 或空对象，并递归扫描整个响应确认不出现 id/nickname/communityId 等用户字段（对应“data 不含用户信息”）；同时提取 EXPIRED_CODE/EXPIRED_REQUEST_ID 供执行记录。
- 步骤 50 按 md 附加条件“若届时刷新令牌也失效，则续期部分前提不满足”：刷新返回 401/code=40101 或其他失败均 raise Blocked。除 md 要求的 TOKEN_NEW 外，同时保存响应中的 REFRESH_NEW，用于按 md 清理要求“本用户通过刷新签发过的其他令牌也分别核查失效”。
- 步骤 60 目标断言：新令牌 GET /me 为 HTTP 200/code=0、requestId 非空、data.id=USER_A、data.communityId=COMMUNITY_A。
- finally 顺序清理 USER_A：先 GET /me 探测（200/code=0 且 id 匹配，或 401/code=40101），探测码为 40101 时先 POST /auth/refresh 并用 updateParam 更新 TOKEN_A/REFRESH_A；DELETE /me 断言 HTTP 200/code=0/data={} 和非空 requestId，提取 DELETE_CODE/DELETE_REQUEST_ID；随后逐一核查注册原访问令牌 TOKEN_A_ORIGINAL、当前 TOKEN_A、主流程刷新签发的 TOKEN_NEW 的 GET /me 均为 HTTP 401/code=40101，注册原 REFRESH_A_ORIGINAL、主流程刷新签发的 REFRESH_NEW、当前 REFRESH_A 的 POST /auth/refresh 均为 HTTP 401/code=40101。每步带 ifParameter 条件，单步失败不阻断后续清理；仅凭 401 不代表账号已删除，以 DELETE 步骤断言与提取记录为准。
- 阻塞/无法表达项：
  - 「XML 格式无法表达」：清理失败/未确认时停止后续任务复用是跨任务调度要求，单 XML 无法表达，调度方须对共享身份串行执行并在清理失败时停止后续任务。执行记录（实际 HTTP/业务码、requestId、脱敏、结论）不属于任务 XML 内容。
  - 「业务接口缺口」：无社区创建 HTTP 接口，社区不足只能 Blocked；无公开 HTTP 可查询令牌剩余有效期，只能按响应 expiresIn 真实等待。注意：按当前仓库实现，访问令牌存储无过期校验（issue 固定返回 expiresIn=7200 且令牌表不记录过期时间），实际执行时步骤 40 预期失败——这正是源用例“不能只返回 expiresIn 而永不校验有效期”要发现的问题，转换不将其转为 Blocked。
- 清理说明：仅清理本用例注册的 USER_A；未注册成功时各清理步骤因 ifParameter 条件跳过。旧/新访问令牌与刷新令牌逐一失效核查，避免残留会话污染共享身份后续用例。
- 可表达性结论：XSD/导入器可表达本文件全部流程；断言核对真实 HTTP/业务码与 requestId，执行记录应脱敏，不记录令牌原文。
