# TC-066 转换说明

- 来源：`docs/test-case/066-invite-closed-topic.md`。XML 独立查询社区、注册 A/B、创建并关闭主题，断言关闭响应及详情状态，验证邀请返回 HTTP 409/code=40901。
- 后续分别查询双方所有状态邀请列表，要求无该主题记录且无后页；查询双方聊天室，要求 A 的主题聊天室仅有发布者、B 无对应聊天室，覆盖公开 HTTP 可观察的无新增邀请/参与关系。
- 无社区或注册/主题准备失败明确 Blocked；无社区创建接口，不将准备成功当目标通过。社区接口当前空列表实现可能阻塞执行。
- finally 对 B/A 分别探测访问凭证，必要时刷新后 DELETE /me；核查原始及最新访问/刷新令牌均 HTTP 401/code=40101，并保存注销业务码与 requestId。部分注册成功或断言失败仍提取凭证并清理。清理失败不能推断账号已删除。
- XSD 可表达本场景流程；OpenAPI 未声明邀请接口的 409 错误响应，XML 显式断言真实 HTTP 和业务码。内部存储/广播/日志不计覆盖。
- 单 XML 不能表达清理失败后停止其他任务调度；调度方必须串行使用共享身份，任一清理失败或未确认时停止环境复用，保留脱敏执行记录，不保存令牌原文。
- 仅生成及离线校验，未执行 HTTP、部署或数据库操作。
