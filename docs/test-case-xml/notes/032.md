## HTTP 接口缺口

- 当前 `UsersControllerImpl.listCommunities()` 固定返回空数组，且未公开社区创建接口。XML 的真实 HTTP 前提检查因此会 Blocked，不能把社区查询成功作为冷却测试通过。若部署服务已提供两个不同社区可继续执行。
- 自然等待后刷新失败按源用例 Blocked；若也无法恢复有效清理凭证，则保留清理失败状态，禁止推断账号已删除。

## XSD / 执行器缺口

- 使用现存扩展 `docs/test-case-xml/task.xsd`（`docs/task.xsd` 当前不存在）。扩展已能表达真实动态等待、条件、参数刷新和 finally。
- “清理失败停止后续用例、禁止共享邮箱并发”是跨任务组约束，单个 XML 无法施加；需执行器串行调度并在清理不确认时停止环境复用。
- CHANGED_AT 缺失或非字符串会明确 Blocked；非空但非法 ISO 字符串由动态 wait 拒绝，产生 WAIT_VALUE_INVALID，XSD 没有将该格式错误转为 Blocked 的策略字段。此类输入仍会清理，不会继续或伪装通过。
- 时间运算采用真实执行器文档 `task-expression-parameters.md` 的 `timestamp(now())`、`timestamp(datetime(param(...)))`；XSD 本身未枚举全部函数。运行端需使用兼容实现。
