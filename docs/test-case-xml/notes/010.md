# TC-010 注册昵称全空白

- 输出：`010-register-blank-nickname.xml`。未执行 HTTP；仅完成离线校验。
- 完整流程：HTTP 读取社区；使用三个空格昵称注册并断言 HTTP 400/code=40001、有错误说明且不签发令牌；同一邮箱有效昵称重新注册并 GET /me 核对 ID、昵称、社区。两次注册均立即提取 ID 和 token，意外成功分支会失败并进入独立 finally 清理；后续主流程停止，因而不会重复注销同一 ID。
- 清理：分别处理意外成功和正常账号；先 GET /me 探测令牌，40101 时刷新；DELETE /me 要求 HTTP 200/code=0/data={} 和 requestId；逐一核查原始和刷新后访问/刷新令牌 HTTP 401/code=40101，保留业务码和 requestId。任何单步失败仍继续其余清理。

## XSD 表达缺口

- 任务不能指定跨任务独占身份/环境锁，也不能表达清理失败自动停止后续任务；执行器必须串行复用邮箱并在清理未确认时停止。
- 无专用执行记录/环境版本/脱敏报告节点；HTTP 状态由执行器步骤结果记录，XML 提取清理业务码和 requestId，不保存令牌原文。
- 本场景的三个空格符合现有 OpenAPI 的 string/maxLength=32，结构化 value 保留空白并绑定前序 HTTP communityId，可直接表达负向请求，不需要 rawBody。

## HTTP 接口与实现缺口

- 当前 UsersControllerImpl.listCommunities 固定返回空数组；无公开创建社区接口。XML 遇此情况明确 Blocked，不将前提成功视为目标通过。
- 初始环境和注册验证码开关由执行环境提供；没有本用例可安全查询全局空环境或配置开关的公开 HTTP 能力，不伪造探测接口。
- AuthControllerImpl.register 构造 Requests.Register，但是否执行 @NotBlank 约束须由真实 HTTP 验证；生成阶段不声称空白昵称已被正确拒绝。
