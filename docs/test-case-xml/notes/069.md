# TC-069 转换说明

- 来源：`docs/test-case/069-invitation-accept-retry.md`。独立查询社区，注册 A/B，创建主题并邀请 B；首次接受提取 ROOM，校验非空 UUID、accepted 及邀请/主题/双方 ID。重试必须 HTTP 200/code=0，仍为 accepted、同一个 I 和 ROOM。
- 首次接受后增加聊天室快照，重试后查询详情要求完整数据不变、成员恰为 A/B 且无重复；查询双方邀请与聊天室列表，要求无后页、该主题邀请和聊天室各仅一条，均对应 I/ROOM。以上均通过公开 HTTP 观察。
- 参与者内部存储没有独立 HTTP 查询字段或端点，不能直接核查 topic_participant 行数；不计为已验证。源文档明确不将没有 HTTP 查询能力的内部存储计入验证。没有捏造参与者接口，不将聊天室成员断言宣称为内部参与者表核查。
- 社区不足、注册或主题准备失败明确 Blocked；不能把前提查询成功当目标通过。业务断言失败仍进入 finally。注册凭证在断言失败时亦提取；不删除来源不明的身份。
- finally 按 B/A 依次探测 /me，访问凭证过期时刷新并更新令牌，DELETE /me 要求 HTTP 200/code=0/data={}、requestId 非空；逐项核查原始及最新访问/刷新令牌均 HTTP 401/code=40101。单步清理失败仍继续其他清理，注销业务码和 requestId 提取供记录，真实 HTTP 结果由执行器记录。不可将单独 401 当作账号删除成功。
- XSD/导入器能表达本场景。OpenAPI 未列出 /me GET 与刷新接口的 401 响应，清理依源文档显式校验真实状态与业务码。跨任务的清理失败停调度无法由单 XML 表达；调度方须串行复用共享身份，任何清理失败/未确认均停止环境复用。执行记录须脱敏，不保存令牌原文。
- 已通过 XSD/语义校验与真实导入器离线转换及配置校验；未执行 HTTP、部署或数据库操作。
