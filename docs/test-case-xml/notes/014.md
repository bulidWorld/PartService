# 用例 014 生成说明

- md 正文把响应字段写成 camelCase（data.expiresIn、data.nextSendAfter），但 OpenAPI 的 SendCodeResult 为 snake_case（expires_in、next_send_after），提取与断言按 OpenAPI snake_case 执行。
- 「不返回验证码」断言实现为响应 data 内不含 "code" 键。
- code 六位随机数字不适用本例（本例只发码不登录），未声明 code 参数。
- finally SQL 清理 verification_code：md 未给出该表列名（resources/db 不在仓库），按 identity_value 列编写 WHERE 条件，列名未核实；purpose 过滤因列名未知而省略（身份值本身由 run UUID 保证唯一，限定力度足够）。
- service_state 按 md 原文：namespace='codes'、state_key="email:<identityValue>:register"，用 compute concat 生成 state_key 后参数绑定。
- 本例无账号 → 跳过 rooms 补录、账号注销与 chat_room 清理。
- 清理步骤以 s_email/codes_key 作 ifParameter 守卫：主流程在发送验证码前阻塞时跳过清理，避免绑定参数缺失。
