# TC-064 转换说明

- 对应源文件：`docs/test-case/064-invite-mismatch.md`。独立查询社区、注册 A/B、设置 B 为 male/2000-01-01，A 创建只允许 female 的主题；邀请严格核查 HTTP 400 与 code=40001。
- 邀请前后使用 B 的无 status 过滤 `/invitations` 查询，确认空列表、hasMore=false、nextCursor=null，核查无新增邀请。公开查询可覆盖本例结果，无未覆盖业务范围；不核查内部存储/广播/日志。
- 注册响应立即独立提取 ID、访问与刷新令牌，断言失败仍发布；finally 先 B 后 A，探测 `/me`，仅在 code=40101 时刷新并更新清理令牌，逐个注销后核查原始及最新访问/刷新令牌失效。保留注销业务码及 requestId；各请求真实 HTTP 状态由执行器记录，令牌标记敏感。
- HTTP 契约缺口：topics.yaml 邀请操作仅声明 200，未声明源要求的 400/40001；XML 明确保留该负向预期，导入不需捏造接口。XSD 无本例阻塞缺口。
- 清理失败必须停止后续共享身份/环境调度，单个 XML 无法控制跨任务调度；需调用方执行该规则。不得把凭证失效当作已注销。
- 仅生成并离线校验，不发送 HTTP、不部署、不改数据库。共享邮箱和手机号须串行复用，初态冲突记录 Blocked，不删除已有账号。
