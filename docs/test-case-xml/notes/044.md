# TC-044 转换说明

- 来源：`docs/test-case/044-topic-title-boundary.md`；标题逐字保留，离线确认恰好80个中文字符。
- 覆盖：公开社区查询、独立邮箱注册（指定邮箱与验证码）、创建80字符标题主题、提取主题ID、以公开详情查询回读同一主题并严格比较完整标题。每次业务响应均明确HTTP 200与code=0。
- 注册后立即独立提取用户ID、访问/刷新令牌及原始令牌副本；断言失败仍发布提取值，finally按可用凭证尝试清理。先GET /me探测，HTTP 401/code=40101时刷新并更新当前令牌；DELETE /me要求HTTP 200/code=0/data={}及requestId，随后分别核查当前和原始访问/刷新令牌HTTP 401/code=40101。未刷新时允许对同一令牌重复核查，用户仅注销一次。
- 无社区或注册准备不成立明确Blocked；凭证不足或响应丢失无法证明清理成功，不视作注销成功。只处理本用例注册响应提取的身份，不能删除来源不明的既有账号。
- XSD缺口：无本例流程表达缺口；跨任务身份串行、清理失败停止后续用例、脱敏HTTP码/requestId与清理结论汇总需执行器保证，单任务XML不能控制其他任务。使用现存`docs/test-case-xml/task.xsd`，旧路径`docs/task.xsd`已删除。
- HTTP接口缺口：没有创建社区接口，公开列表不足时阻塞；内部存储与广播不计作验证。现有创建及详情接口足以验证80字符完整保存，无目标场景接口缺口。
- 离线验证：使用`validate.py`检查XSD、参数依赖、OpenAPI绑定和四参数断言AST/沙箱白名单；只生成，未运行HTTP。
