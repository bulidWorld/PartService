# TC-089 转换说明

- 源：`docs/test-case/089-chat-outsider-history.md`；XML：`089-chat-outsider-history.xml`。只生成，未执行 HTTP。
- 独立注册 A/B/C，创建主题、邀请、接受及消息，C 请求历史必须真实 HTTP 403、code=40301；要求错误 data 为空且错误响应不含正文、消息 ID 或成员 ID。
- 越权前后以成员 B 查询相同消息页，逐字段比较并核查唯一消息未撤回；以成员 A 查询房间并比较全部公开房间字段及成员集合。
- HTTP 缺口：Room 不暴露最后消息时间；只有 POST /rooms/{roomId}/read 写已读位置，无读取已读位置接口。因此最后核查成功后显式 Blocked，已验证部分不得称整个用例通过。不发写已读请求代替只读核查。
- XSD 可表达所需请求、条件、快照和 finally，无额外 XSD 缺口。OpenAPI 未列消息历史 403 错误响应，业务码按源用例断言。
- 社区不足或准备 HTTP 失败显式 Blocked；不臆造社区或删除未知账号。注册响应立即独立提取用户及令牌，断言失败仍供 finally 清理。
- finally 按 C/B/A 逐个探测令牌，40101 时刷新并更新凭证，注销后核查注册原令牌及当前令牌均失效。单步清理失败仍尝试其他用户。清理失败必须停止跨任务调度、共享身份串行复用、脱敏保存实际 HTTP/业务码/requestId 由执行器负责，单 XML 无法实施跨任务停止。
