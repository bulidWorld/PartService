# TC-140 转换说明

- 来源：`docs/test-case/140-persistence-restart.md`；产物：`140-persistence-restart.xml`。
- 源用例结论即为阻塞：公开契约没有服务重启 HTTP 接口，仅允许 HTTP 时无法主动重启服务并建立重启前后对照。保留源用例唯一 HTTP 步骤 `GET /communities`（无鉴权、Accept JSON），核查服务可达（HTTP 200、业务码 0、社区数组、requestId 非空）后抛出 `Blocked`；查询准备失败同样阻塞，查询成功不代表目标场景通过。
- 业务接口缺口：六个 rest-api YAML 均无服务重启接口；wait 节点只能等待、不能重启，不能替代。单纯连续查询不能证明重启后数据保留，故未声称通过，也未虚构重启接口或用后台操作替代。
- 无注册用户、无数据写入，省略 finally 清理。
- XML 格式无法表达：跨任务「清理失败停止后续任务」由调度器实现，单任务 XSD 无此配置（本场景无清理，不涉及）；服务重启动作无对应步骤类型，属业务接口缺口而非 XSD 缺口。
- 仅离线生成和校验，未执行 HTTP。断言仅使用执行器白名单支持的 `isinstance`、`dict`、`list`、`assert` 与 `raise Blocked`。
