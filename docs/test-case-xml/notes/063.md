# TC-063 转换说明

- XML 完整独立执行：查询社区、注册 A 并立即提取账号及新旧凭证、创建主题、邀请固定不存在的 UUID；断言 HTTP 400/404、整数业务码非 0 且没有可用邀请 ID。
- finally 先 GET /me 探测凭证，必要时刷新并更新清理凭证，然后 DELETE /me；分别核查注册及可能刷新签发的访问、刷新令牌均返回 HTTP 401/code=40101，记录删除业务码和 requestId。注册断言失败仍独立提取创建的账号与凭证。
- 社区缺失或注册准备失败明确 Blocked。沿用源用例的独立空业务环境前提；公开 HTTP 没有按任意用户 ID 查询用户的接口，无法额外证明固定 UUID 不存在。未验证内部邀请存储、广播或日志；源用例目标的可观测结果以邀请响应判断。
- OpenAPI 仅声明邀请成功 200 响应，未声明源用例要求的 400/404 错误响应；XML 显式断言源要求，不据成功契约弱化负向预期。请求 UUID 符合契约，无需 rawBody。无 XSD 表达缺口。
- 单 XML 的 finally 无法控制跨任务调度：清理失败、响应丢失或凭证不足必须由执行者停止后续任务及身份复用；不能把失效核查单独当作账号删除证明。HTTP 状态、业务码与 requestId 应从执行报告保存，令牌不保存明文。
- 本次只生成并离线校验，不发送 HTTP、不部署、不修改数据库。
