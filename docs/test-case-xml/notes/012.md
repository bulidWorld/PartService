# 用例 012 生成说明
- 六位随机数字验证码固定为 "123456"；昵称按 md 规则需 UUID 前 12 位，XSD 无 substring，改用固定昵称 "测012甲"。
- 邮箱用 compute 的 concat+run 生成，两次注册请求引用同一 a_email 实现重复身份。
- 第二次注册预期 HTTP 409/code=40901；该负例同样声明 b_id/b_access/b_refresh 提取，意外成功时 finally 兜底注销。
- finally：注销 A（DELETE /me 200）并验证令牌失效（GET /me 401/40101），再以 b_access 守卫兜底注销第二次注册可能产生的账号。
- 本例未创建主题，SQL 聊天室清理无对象，省略。
