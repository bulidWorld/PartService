## HTTP 接口缺口及实现风险

UsersControllerImpl.listCommunities 当前固定返回空数组，且没有公开创建社区接口；XML 根据实际查询响应 raise Blocked，不能将准备查询成功算场景通过。TopicRepository.matches 在任意限制存在时先检查 birthDate，可能导致仅性别限制也拒绝 B；本用例保持期望可见断言，未运行故不能报告已复现。

## XSD 与执行器边界
