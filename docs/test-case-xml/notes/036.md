# TC-036 转换记录

- 来源：`docs/test-case/036-topic-missing-title.md`。已编码社区准备、邮箱注册、缺少 title 的 rawBody 请求、主题及房间空列表查询，以及 finally 账号注销和全部已签发令牌失效核查。注册立即提取用户 ID 和令牌；准备失败停止业务并进入清理。
- 使用现存 `docs/test-case-xml/task.xsd`；原引用 `docs/task.xsd` 当前不存在。项目 base_url 配置为 `http://127.0.0.1:10201/api/v1`。邮箱为源用例指定邮箱，不可与其他使用此邮箱的任务并行执行。
- 清理先通过 GET /me 探测访问令牌，401/40101 时刷新，保存原始与新签发令牌后注销；失败仍尝试其余 finally 节点。注销必须 HTTP 200/code=0/data={}/非空 requestId；全部令牌核查必须 HTTP 401/code=40101。
- XSD 缺口：任务只能管理自身 finally，无法表达跨任务“清理失败停止后续任务”、相同身份互斥、自动填写环境版本/执行时间的脱敏执行记录；须由调度器与执行报告实现。没有妨碍本用例 HTTP 流程的 XSD 缺口。
- HTTP 接口缺口：无社区创建接口，社区列表不足时明确 Blocked；不能核验内部关系、数据库或广播，本用例也不作这些结论。
- 错误消息要求包含 title 或“标题”，避免仅凭 400 断言对应字段。GET 列表依据公开契约断言 data.items=[]。
- 仅做离线结构、参数和断言 AST 验证，未发送 HTTP 请求，实际执行结果仍为未执行。
