# 用例 003 生成说明
- 缺少 required 字段 nickname 违反 OpenAPI Schema，按规则必须用 rawBody；rawBody 不插值且与 body 互斥，无法携带前序响应提取的真实 C1，communityId 改用固定 UUID 字面量 00000000-0000-0000-0000-000000000000（缺失昵称与不存在社区按本套用例约定均为 400/40001）。
- rawBody 内邮箱、验证码为固定字面量（tc-003-bad@example.com、123456），纯负例注册可用固定值。
- md 第 2 步“生成 missingCommunity=generateUUID()”为模板残留（本请求未使用），省略；GET /communities 步骤保留作环境前提（无社区时 Blocked）。
- 负例注册仍声明 b_id/b_access/b_refresh 提取，意外成功时 finally 用 b_access 兜底注销。
- 预期按 md 写死 HTTP 400/code=40001。
