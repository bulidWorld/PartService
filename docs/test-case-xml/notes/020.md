# TC-020 转换记录

- 来源：`docs/test-case/020-login-unregistered.md`；输出保留发送登录验证码和未注册邮箱登录的两个 HTTP 步骤，显式断言 HTTP 401 / 业务码 40101 / 身份未注册，并检查响应未返回令牌。发送验证码准备失败标记阻塞；验证码错误 HTTP 400 / 40001 标记阻塞，不误报目标通过。
- 已只读核对 `auth.yaml`、`AuthControllerImpl`、`UserRepository.verifyCode`。当前实现发送的验证码固定为 `000000`，登录校验未由注册验证码开关控制；按源用例要求仍发送 `246810`，因此按当前实现运行预计会阻塞，未实际发送 HTTP。
- HTTP 接口缺口：无公开身份是否已注册的查询，也无匿名用户存储查询。独立空环境和邮箱未注册初态需由执行环境保障；拒绝响应无令牌可观察，但“未隐式创建用户”的内部持久化效果不能独立通过 HTTP 核实。没有注册成功步骤，不新增账户，因此无本用例自建账号需要注销；若意外登录成功，不能删除来源不明账号。
- XSD 缺口：任务模型未定义跨任务邮箱身份互斥以及前一任务清理失败就停止后续任务的全局控制，需由外部执行器保证串行复用。任务自身两个步骤和阻塞分支可完整表达。
- 路径差异：指定的 `docs/task.xsd` 已不存在，采用现存 `docs/test-case-xml/task.xsd`。服务地址由导入项目配置，XML 不部署或重置环境。
- 离线验证：使用 `validate.py` 检查 XSD、参数引用、断言 AST 与请求 OpenAPI；不执行 HTTP，不记录验证码/令牌的运行输出。
