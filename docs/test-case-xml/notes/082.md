- 文件：`082-chat-two-senders.xml`。完整保留社区发现、独立双用户注册、主题/邀请/接受、A/B 使用相同 `shared-id` 发送以及 A 查询消息的串行流程。
- 分别核对真实 HTTP 200、code=0、requestId、消息 ID、roomId、senderId、内容及元数据；第二条消息与第一条 ID 必须不同，查询必须同时找到二者且发送者分别为 A、B。接受邀请核对非空 UUID roomId。
- 所有注册响应立即独立提取 user.id/accessToken/refreshToken，断言失败仍提取；保留原始令牌用于失效核查。准备失败明确 Blocked，不能将社区查询成功视为目标通过。

- 未覆盖：内部幂等索引实现、广播与日志不可通过所列 HTTP 直接观察，不计入已验证范围。
- XSD/HTTP 缺口：无社区创建接口；社区不足必须阻塞。单 XML 无法控制跨任务调度，任何清理失败或未确认时，调度方必须停止后续用例和共享身份复用。身份必须串行使用，不能删除来源不明的已有账号。
- 仅生成与离线校验；未运行 HTTP、部署或改数据库。
