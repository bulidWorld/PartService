# 用例 021 生成说明

- 本例无注册步骤，无任务级参数，无 finally（md 清理模板中的房间补录、账号注销、chat_room 删除均无适用对象）。
- GET /topics 与 GET /topics/receipts 按 md 带 query limit=20（OpenAPI limit 为 integer 1~100，用 valueType="integer" 字面量 20）。
- 五个受保护接口（GET /me、/topics、/topics/receipts、/rooms、/me/rating-summary）均 auth mode="none"，断言 HTTP 401 与业务码 40101，与 md 1:1。
- 断言沙箱禁用 re：社区每项 id 的 UUID 格式无法断言，仅断言 id/name 非空。
- c1 按 md 步骤 1 提取，本例后续步骤未使用。
