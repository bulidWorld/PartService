# TC-068 转换说明

- 独立完成社区查询、A/B 注册、主题发布、邀请、B 拒绝、rejected 列表及 B 空聊天室列表核查。拒绝响应必须 HTTP 200/code=0、ID=I、status=rejected，并明确包含 roomId=null；列表只有一条 I，核对主题及双方用户 ID、rejected 和 roomId=null，且无后续分页。
- GET /rooms(B) 必须 items=[] 且无后续分页，因此也证明不包含 T 对应房间。没有将准备请求成功当作目标通过。
- ID/token 全来自本文件前序响应；注册立即提取 user.id/accessToken/refreshToken 及原始令牌，即使断言失败仍提取并进入 finally。无社区或注册前提失败则 Blocked，不删除来源不明的已有身份。
- finally 按 B、A 独立尝试 GET /me 探测、过期时刷新更新清理凭证、DELETE /me、所有注册原始及最新访问/刷新令牌失效核查。注销要求 HTTP 200/code=0/data={} 且非空 requestId；失效核查要求 HTTP 401/code=40101。清理单步失败仍继续其他步骤及用户；不能把 401 本身当成账号已删除。
- 未覆盖内部存储、广播、日志及通知投递；这些没有公开 HTTP 查询证据，符合源用例观察范围。目标业务 HTTP 接口无缺失；OpenAPI 未完整声明失效核查的 401 错误体，40101 依源用例要求断言。
- XSD 无法表达清理失败后的跨任务停止调度；共享身份必须串行执行，任一用户清理失败、未确认或凭证不足时，外部调度必须停止环境复用。响应丢失无法可靠回收的情况须记清理未确认。
- 仅生成并离线校验，未运行 HTTP、未部署或修改数据库。导入项目 base_url 为 http://127.0.0.1:10201/api/v1，远程地址由执行者配置。
