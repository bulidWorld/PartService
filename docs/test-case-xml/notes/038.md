# TC-038 发布主题缺少详情

- 输出：`038-topic-missing-detail.xml`。未发送 HTTP，仅离线生成、校验。
- 覆盖：查询真实社区、独立邮箱注册并立即提取用户及访问/刷新令牌；原始 JSON 省略 detail，断言 HTTP 400 / 40001 且 message 指向 detail/详情；查询 open 主题和聊天室均为空；finally 探测访问令牌，必要时刷新，注销，分别检查所有原始及新签发令牌失效。
- 使用 `rawBody` 绕过接口 TopicRequest 的 detail 必填预检，确保真正发送负向请求。注册邮箱按源用例为 `782213745@qq.com`，不能与其他使用同邮箱的任务并行执行。生成过程多 agent 并行与运行任务并行不同。
- HTTP 接口缺口：没有公开社区创建接口，社区为空时 Blocked；没有内部关系查询接口，不能证明内部无写入，仅核查公开主题及聊天室列表。依赖独立无业务数据环境；注册准备失败标记 Blocked，不删除已有账号。
- XSD 表达缺口：任务内部支持 finally 和条件刷新，但无法描述跨任务“清理失败/未确认即停止后续用例”，须由执行器调度保证。响应丢失或成功注册但缺失 ID/凭证时无法仅靠公开接口安全恢复清理，必须记录未确认并停止复用环境；不能把 401 当作注销证明。
- XSD 路径差异：原指定 `docs/task.xsd` 不存在，按现存 `docs/test-case-xml/task.xsd` 生成。
- 请求实际 HTTP/业务码、requestId 和脱敏响应由执行器逐步记录；XML 提取清理 requestId 和业务码，敏感令牌均标记 sensitive。
- 断言采用执行器支持的四参数入口及白名单 builtins，无 type/repr/反射调用。
