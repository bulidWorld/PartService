# 用例 005 生成说明
- 昵称 33 个“测”超过 maxLength=32，违反 OpenAPI Schema，必须用 rawBody（CDATA 原样 33 字）。
- rawBody 不插值，communityId 无法引用真实 C1，改用固定 UUID 字面量 00000000-0000-0000-0000-000000000000（超长昵称与不存在社区按本套用例约定均为 400/40001）。
- rawBody 内邮箱、验证码为固定字面量；纯负例注册可用固定值。
- md 第 2 步生成 missingCommunity 为模板残留，省略。
- 负例注册声明 b_id/b_access/b_refresh 提取，finally 以 b_access 兜底注销意外成功账号。
- 预期按 md 写死 HTTP 400/code=40001。
