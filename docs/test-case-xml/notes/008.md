## HTTP 接口缺口

- `UsersControllerImpl.listCommunities()` 当前固定返回空数组，且无公开创建社区接口。XML 对社区空列表显式 `raise Blocked`，不得将社区请求成功记作注册通过。部署实现若返回可用社区，则继续完整业务流程。
- 无公开注册验证码校验开关接口与手机号占用查询；开关由执行环境提供，注册返回 409 时标记阻塞且不删除已有身份。
- 注册响应丢失或仅返回用户 ID 而缺凭证时，公开接口不足以安全恢复本次创建账号，清理判定未确认，停止复用环境。

## XSD 表达缺口

- XSD 仅定义单任务，不能强制跨任务身份互斥、上一用例清理失败后停止后续任务或空环境检查；运行器需执行这些规则。
- 无标准化执行报告/脱敏 HTTP 响应存档元素、实际 HTTP 状态码提取表达式；断言显式检查真实 HTTP 状态及业务码，提取清理 code/requestId，但逐用户持久化执行时间、HTTP 状态及清理结论需运行器报告。令牌参数标记 sensitive，报告不得保存原文。
- XSD 不包含 BASE_URL 项目配置元素，须导入时使用正确项目环境。无 need compute 的推测性函数调用。
