# 用例 008 生成说明
- communityId 为格式合法的随机 UUID（generateUUID()），Schema 合法，用结构化 body 绑定参数。
- missingCommunity 在 compute 节点用 generateUUID() 生成（每次执行独立取值）；不用任务级 function 参数，因为离线校验会对 fixed 参数的函数文本按 uuid format 校验，而 compute 输出仅做类型检查。
- 六位随机数字验证码固定为 "123456"；邮箱用 compute 的 concat+run 生成。
- 负例注册声明 b_id/b_access/b_refresh 提取，finally 以 b_access 兜底注销意外成功账号。
- 预期按 md 写死 HTTP 400/code=40001（不存在社区按参数错误处理）。
