# TC-040 转换记录

- 完整编码社区查询、独立邮箱注册、超长标题原文 rawBody 请求、主题与房间空列表断言、finally 注销及所有签发访问/刷新令牌失效核查。只生成与离线校验，未执行 HTTP。
- 请求标题从源 Markdown 原样复制；rawBody 绕过 TopicRequest.title maxLength=80 的导入校验，认证仍引用本次注册令牌。错误断言为 HTTP 400/code=40001，message 提及 title 或标题。
- 清理前 GET /me 探测有效性；401/40101 时使用本次刷新令牌刷新并更新当前会话，保留原始及新增令牌作失效核查。注销失败仍继续后续核查；不能仅凭 401 判定删除成功。参数脱敏，执行日志应逐步保留 HTTP/业务码及 requestId，不保留令牌。
- XSD 缺口：不能编码跨任务“清理失败或未确认则停止后续用例/禁止环境复用”的调度策略，须由执行器执行；单文件 finally 失败会使任务不通过。无当前目标场景所需的其他 XSD 缺口。
- HTTP 接口缺口：没有社区创建接口；无社区时明确 Blocked。内部关系记录没有公开查询接口，不宣称覆盖内部写入；HTTP 列表查询已覆盖。
- 环境前提：独立无用户及业务数据的测试环境；固定邮箱必须串行复用。本用例独立注册，只清理自己实际创建的 USER_A；注册响应异常时仍按独立提取的 ID/token 尝试 finally。
