# 用例 007 生成说明
- communityId "not-a-uuid" 违反 uuid format，按规则必须用 rawBody；请求体全部为固定字面量（含 not-a-uuid）。
- 邮箱、验证码为固定字面量（tc-007-bad@example.com、123456），纯负例注册可用固定值。
- md 第 2 步生成 missingCommunity 为模板残留，省略；GET /communities 提取的 c1 未被请求体使用。
- 负例注册声明 b_id/b_access/b_refresh 提取，finally 以 b_access 兜底注销意外成功账号。
- 预期按 md 写死 HTTP 400/code=40001。
