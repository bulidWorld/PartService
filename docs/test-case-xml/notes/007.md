- `UsersControllerImpl.listCommunities()` 当前固定返回空列表；没有公开创建社区接口。执行将明确 Blocked，不能将社区查询成功算作注册场景通过。
- 没有公开的身份占用预检接口；独立空环境及相同邮箱串行复用须由执行者保证。年龄在契约中以 birthDate 表达，核查 birthDate、gender、avatarUrl 为空。

## XSD / 执行器缺口

- XSD 没有项目 base_url 字段，需在导入目标项目配置环境地址。
- 没有跨任务串行锁、清理失败后停止其他任务/环境复用、执行记录表或按状态统一脱敏导出的声明。执行器须保存各清理步骤实际 HTTP/业务码、requestId，只有注销成功和失效核查全部成功才允许后续用例；缺失 ID/令牌或响应丢失时标记清理失败/未确认，不得仅凭 401 判断删除。
- 不使用未定义白名单的 compute。清理探测 40101 表示令牌无效，HTTP 无法严格区分自然到期与其他失效原因；使用本次刷新令牌恢复。
- finally 的单条件只能按已提取令牌判断执行；注册确实成功但响应丢失/令牌缺失时无法自动定位和注销，必须停环境复用，由执行器记录未确认。
