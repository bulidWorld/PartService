# 用例 019 生成说明

- 伪造刷新令牌 `invalidToken` 用任务级 function 参数 `generateUUID()` 生成（XSD 支持，无缺口）。
- 负例刷新（POST /auth/refresh）按"负例意外成功兜底"约定声明 extractParam 提取 data.accessToken/data.refreshToken/data.user.id（r_access/r_refresh/r_id）；正常情况下提取为 null，finally 两步由 ifParameter="r_access" 守卫跳过；若意外签发会话则 DELETE /me 兜底注销并验证 401。
- 本例无注册用户、无主题/聊天室，md 清理模板中的 GET /rooms 补录与 chat_room 删除不适用，finally 仅保留上述兜底两步。
- 断言沙箱禁用 re：社区每项 id 的 UUID 格式无法断言，仅按样例断言 id/name 非空。
- c1 按 md 步骤 1 提取，本例后续步骤未使用（md 要求保留步骤）。
