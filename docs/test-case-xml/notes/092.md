- 来源：`docs/test-case/092-chat-outsider-recall.md`。生成独立同 stem XML，社区从本文件 GET /communities 提取；独立注册 A/B/C，创建主题、邀请/接受、A 发送消息，C 非成员撤回必须 HTTP 403/code=40301。ROOM 检查非空 UUID。所有 REST 显式 auth、真实 HTTP 状态/业务码断言。
- 越权前后分别查询完整消息页和聊天室：核查原消息 recalled=false、正文不变、消息总数不变、页面完整对象相同、成员及聊天室完整对象相同。错误响应 data 仅允许 null/{}、无额外字段，错误 message 不得包含正文及成员姓名/ID，验证可观察的隐私泄露范围。

- 当前 UsersControllerImpl.listCommunities 固定返回空数组，且没有公开创建社区接口，执行时无社区即 Blocked。此情况下注册及目标越权行为均未覆盖。OpenAPI 未声明 recall 的 403 和多数鉴权 401 响应；XML 按源要求断言，不改源契约。XSD/导入器能够表达已支持部分，但不能弥补上述 HTTP 可观察性缺口。
