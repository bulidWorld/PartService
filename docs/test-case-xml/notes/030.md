# TC-030 转换说明

- 保留社区发现、注册立即提取用户 ID/访问和刷新令牌、更新前 GET 完整资料、rawBody PATCH 源 avatarUrl、GET 完整资料对比、finally 注销及原始和最新令牌失效核查。拒绝预期保持 HTTP 400/code=40001。只生成，未执行 HTTP。
- HTTP/判定前提缺口：源用例标记待附件规则确认；契约 avatarUrl 仅 format=uri，没有受控域名、类型、大小规则或查询接口。固定参数 ATTACHMENT_RULES_CONFIRMED=false 在注册前通过 onFalse=blocked 停止。确认规则后须评审指定 URL 确为拒绝样本，再更新门禁；不能把社区查询成功记作目标通过。
- HTTP 前提缺口：UsersControllerImpl.listCommunities 固定空数组，没有公开创建社区接口；运行时可能更早因缺社区 Blocked，不虚构数据。
- 实现观察：UsersControllerImpl.updateUser 直接保存非空 avatarUrl，未见受控附件校验；这是规则确认后的潜在实现差距，不据此修改源预期。
- 清理探测 401 后刷新，更新最新令牌；注销成功单独断言，原始/最新令牌分别核查失效。未创建账号跳过，不能仅凭 401 推断账号删除。
- XSD 缺口：单任务无法强制跨任务邮箱串行复用和清理失败停止后续任务；须由执行器汇总 finally 结果并保存脱敏 HTTP 状态/业务码/requestId，失败或未确认时停止复用环境。BASE_URL 由项目配置。
- 使用现存 docs/test-case-xml/task.xsd；原 docs/task.xsd 不存在。四参数断言兼容实际沙箱，无日期计算。
