# TC-112 转换说明

- 来源：`docs/test-case/112-rating-comment-too-long.md`。目标：评价评论超过 500 字符被拒，HTTP 400/code=40001、响应不返回评价 ID，随后公开评价列表为空。
- 步骤转换：`GET /communities` 取 COMMUNITY_A（不足即 Blocked，无社区创建接口）→ `GET /rating-categories` 复核 reliable（缺失即 Blocked）→ 注册 A（邮箱 782213745@qq.com）/B（手机号 13900000002）→ A 建主题「周末公园散步」→ B 直接接受主题 `POST /topics/{T}/accept`（roomId 校验非空 UUID，order 60）→ A 以 `POST /topics/{T}/ratings` 提交超长评论（order 80）→ `GET /users/{USER_B}/ratings?limit=20` 公开查询断言列表为空（order 90）。
- 接口迁移适配：转换期间 `invitations.yaml` 已被移除，源用例步骤 6（`POST /topics/{T}/invite`）在现行 OpenAPI 中无对应接口；参与关系改由被邀请方直接 `POST /topics/{topicId}/accept` 建立（返回 TopicReceipt，含 status=accepted 与 roomId）。本文件按现行接口将源用例步骤 6-7 合并为该接受请求，A 邀请 B 的意图由主题创建者 A 建题、B 接受实现；roomId 提取与源用例一致。
- 超长评论构造：`RatingRequest.comment` maxLength=500（实现 `@Size(max=500)`），501 个「评」的字面量 body 绑定会被离线 OpenAPI 校验拒绝；XSD rawBody 不解析、不插值，无法携带前序提取的 toUserId=USER_B，写死/伪造 UUID、省略必填字段或占位符文本均违反源用例「不能写死或臆造」约束（同 TC-009/TC-014「动态负向 JSON」缺口）。因此未使用 rawBody，改用运行时参数引用：order 70 由 TOKEN_A 创建载体主题（`TopicRequest.detail` 无 maxLength，detail=501 个「评」），提取 `data.detail` → COMMENT_TOO_LONG，order 80 的 comment 字段引用该参数，toUserId 仍为真实 USER_B。载体主题随 USER_A 注销时由 `DELETE /me` 连同其发布主题一并删除。
- 目标断言直接 assert：HTTP 400、code=40001、requestId 非空、响应键仅限信封（code/message/data/requestId）且 data 为空对象或 null（不返回评价 ID）；公开列表断言 items=[]、hasMore=false、nextCursor=null。业务码 40001 以源用例 md 为准，OpenAPI 未声明该接口 400 响应。
- 准备失败（社区、分类、注册、主题、接受、载体主题）raise Blocked 并仍执行清理；载体主题回显不足 501 字符时视为无法取得超长评论文本而 Blocked。
- finally 顺序清理 B/A：先 `GET /me` 探测（200/code=0 且 id 匹配，或 401/code=40101 时先 `POST /auth/refresh` 并用 updateParam 更新 TOKEN/REFRESH）→ `DELETE /me` 断言 200/code=0/data={}、非空 requestId，提取业务码与 requestId 供记录 → 旧/新访问令牌 `GET /me`、旧/新 refreshToken `POST /auth/refresh` 逐一核查 HTTP 401/code=40101。单步失败不阻断后续清理；401 不代表账号已删除。仅清理本用例实际创建的用户。
- 无法表达项：①「XML 格式无法表达」：rawBody 不支持参数引用与插值，无法按源用例字面同时携带动态 toUserId 与超长评论，本文件以载体主题回显 + 运行时参数引用绕过，未阻塞；清理失败后调度器停止后续共享身份任务、逐用户清理结论与脱敏执行记录需执行器/人工保证。②「业务接口缺口」：无社区及评价分类创建 HTTP 接口，不足时按源用例记录阻塞；OpenAPI 未声明评价提交 400 及 `GET /me`、refresh 的 401 响应，断言按源用例记录真实 HTTP/业务码。
- 可表达性结论：XSD/导入器可表达本文件全部流程与断言，无需 compute/wait/rawBody。
