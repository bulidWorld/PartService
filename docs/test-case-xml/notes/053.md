# TC-053 转换记录

- 保留社区查询、独立邮箱注册、创建主题、两次关闭、开放流排除及详情查询。关闭响应均校验 HTTP 200/code=0、同一主题 ID、closed 和原有主题字段不变；补充 closed 流验证历史可查。
- 为核查不可重复写入成员，使用公开 GET /rooms 保存本主题唯一聊天室 ID，关闭前、两次关闭后校验 members 恰为发布者一个元素；最后再次查询聊天室列表验证仍只有同一主题的一个聊天室。GET /rooms/{roomId}/messages 验证空历史仍可访问。本用例未发送消息，因此只覆盖空聊天历史的可访问性，不声称验证已有消息保留。所有结果仅限 HTTP 可见状态，不证明内部存储没有冗余写操作。
- 注册立即提取用户 ID 和全部凭证，断言失败仍保留提取；finally 探测过期、必要时刷新，再 DELETE /me 并分别核查注册原始及刷新后当前访问/刷新令牌全部 HTTP 401/code=40101。注销须 HTTP 200/code=0/data={}/非空 requestId。任一清理失败不得以失效响应推断账号已删除。
- HTTP 前提缺口：缺社区时 Blocked，公开接口无法创建社区；共享邮箱必须串行执行，已有身份不可擅自删除。房间唯一性检查使用源文档的无用户及业务数据环境前提。
- XSD/调度缺口：单 XML 无法强制跨任务身份互斥、清理失败停止后续调度及保存脱敏执行记录；由执行者落实。清理状态未确认时停止环境复用。
- 只生成及离线 XSD/真实导入器校验，不运行 HTTP、不部署、不改数据库。使用现存 docs/test-case-xml/task.xsd，不恢复源 XSD。
