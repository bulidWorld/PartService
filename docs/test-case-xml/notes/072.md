# TC-072 转换说明

- 源：`docs/test-case/072-invitation-forged-actor.md`。独立获取社区，依次注册 A/B/C、创建主题与邀请；C 接受和拒绝均检查真实 HTTP 404、业务码 40401，随后 B 查询邀请仍 pending、标识和双方用户不变、roomId 为空。
- 为“成员不变”补充 A/B/C 操作前后 `GET /rooms`，在独立空环境中均断言完整空页，确认未产生参与本用例用户的聊天室；不声称核查数据库内部成员记录或广播。
- 注册响应无论断言是否成功均提取本次 user.id 和两类令牌。finally 按 C/B/A 顺序探测访问令牌；过期则刷新更新清理凭证，逐用户 DELETE /me 并核查最初与最新访问/刷新令牌均失效；单步失败仍继续其他清理。
- 前提缺失（社区不足、注册失败）明确 Blocked。共享邮箱、手机号须串行执行；不得清理未知已有账号。清理失败跨任务停止调度无法由单份 XML 强制，执行器/调度者须据 finally 失败停止环境复用；不能将 401 当作注销成功。
- HTTP 契约缺口：OpenAPI 未列出邀请操作的 404/40401 错误响应，按源用例显式断言；已公开的接口足以覆盖本用例外部行为。XSD 无新增缺口。
- 仅生成并离线校验 XML，未发 HTTP、未部署、未改数据库。
