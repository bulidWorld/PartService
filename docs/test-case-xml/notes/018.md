# 用例 018 生成说明

- 昵称规则为「测」+ UUID 前 12 位，无 substring → 固定昵称「测018甲」。
- 验证码 code 六位随机数字无法生成 → 固定 "123456"（环境已关闭校验）。
- 「保存 A.access_token=data.accessToken」用 updateParam 覆盖 a_access（并同步覆盖 a_refresh 保持登记一致）；updateParam 提取失败会置 null，finally 靠 ifParameter 守卫跳过注销。
- expiresIn 断言为 int 且 >0（排除 bool），user.id 与注册时 a_id 相等。
- 本例无主题发布 → finally 跳过 GET /rooms 补录与 chat_room SQL 清理。
