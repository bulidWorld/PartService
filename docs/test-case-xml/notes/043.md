# 用例 043 生成说明

- 昵称：md 要求"测+UUID 去连字符前 12 位"，compute 无 substring/去连字符截取能力 → 改为固定昵称（A=测043甲、B=测043乙、C=测043丙、D=测043丁）。
- 验证码 code：compute 无随机数字函数 → 固定 "123456"（测试环境已关闭验证码校验）。
- 生日：md 要求"当前 UTC 日期减 20/30 年"，compute 节点设置 timezone="UTC" 使 today() 取 UTC 日期，再用白名单内 format_date(add_years(today(), -20)) / -30 生成 yyyy-MM-dd；add_years 内置闰日钳制（2/29→2/28），与 md 的闰日处理约定一致。服务端按 LocalDate.now(ZoneOffset.UTC) 计算年龄，故 UTC 日期基准可精确命中 20/30 岁的包含边界。
- 断言沙箱禁止 re，社区条目 id 的 UUID 格式只断言非空（与 002 样例同风格），未做正则校验。
- 清理：本用例没有任何成功的接受请求，不会产生聊天室，md 清理第 1/7 步"无聊天室则跳过"，故省略 GET /rooms 补录与 chat_room 的 SQL 清理。
