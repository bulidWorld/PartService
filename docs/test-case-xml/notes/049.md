# TC-049 转换说明

- 生成独立双社区注册、A 创建主题、B 空列表、隐藏主题与不存在主题均为 HTTP 404/code=40401 的核查；比较错误文案，均要求 data=null，避免标题、详情、发布者或成员数据泄露。
- 当前 UsersControllerImpl.listCommunities 固定返回空数组；执行时会在准备步骤明确 Blocked。没有社区创建 HTTP 接口；未执行目标场景，不能把社区查询成功计为隔离通过。前两项社区须为不同有效 ID。
- 注册响应即提取用户及全部令牌，断言失败也保留清理输入。finally 按 B、A 顺序探测令牌、必要时刷新、DELETE /me，并检查注册及刷新后的访问/刷新令牌均为 401/40101。单用户清理失败不阻止另一用户清理。
- OpenAPI 未列出主题详情的 404 和刷新接口的 401 业务响应，XML 依据源用例及实现显式断言。错误 data=null 与实现一致，同时比较两次 message；不比较逐请求变化的 requestId。
- XSD 无跨任务停调度机制；执行器必须串行使用共享身份、脱敏记录各请求实际状态/业务码/requestId，任一清理失败或未确认时停止后续任务。HTTP 无法证明环境完全空白，须由执行环境保证。
- 仅生成及离线校验，不执行 HTTP、不部署、不改数据库。
