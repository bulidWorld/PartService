- XSD 缺口：compute 无 YYYY-MM-DD 纯日期格式化函数（http_date 为 RFC1123 风格，不符合 birthDate 的 date 格式），md 步骤 3 的 tomorrow 无法表达；改用固定远期日期 "2099-01-01"（Schema 合法、在可预见的执行期内始终为未来日期），语义等价于"生日为未来"，业务拒绝 400/40001。
- 原资料 P 通过 GET /me 提取 p_nickname/p_gender/p_birth，修改失败后的 GET /me 断言三字段与 P 相等。
- 验证码 code 固定 "123456"；昵称固定 "测025甲"。
