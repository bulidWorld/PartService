# TC-091 转换说明

- 保留独立社区查询、A/B/C 注册、创建主题、邀请并接受、发送消息及 C 越权标记已读（lastReadMessageId 来自本文件消息响应）。每 REST 显式 auth，检查真实 HTTP、业务码和 requestId；roomId 核查 UUID。注册立即提取 user.id/accessToken/refreshToken，断言失败仍发布并纳入 finally。
- 越权前后分别由成员 A 查询聊天室和消息快照；断言 C 不在成员中，目标 HTTP 403/code=40301、data=null，响应不含消息正文、A/B ID 或昵称；随后核对完整聊天室和消息页面一致、消息仍未撤回且只有一条。
- 未覆盖/明确 Blocked：Room 契约只有 id/topicId/ownerId/members/createdAt，没有最后消息时间及已读位置字段；GET 消息也不返回已读位置，POST /read 仅写入并回显，不能证明无副作用。完成可观察断言后 raise Blocked，完整源用例不会误标通过；消息 createdAt 一致仅验证消息时间，不能替代聊天室最后消息时间。
- finally 按 C/B/A 独立探测 GET /me，过期时刷新更新当前凭证，DELETE /me 后核查原始和当前访问/刷新令牌均 HTTP 401/code=40101；清理单步失败继续其他用户。所有令牌参数敏感。注册失败不删除来源不明身份。
- XSD/HTTP 缺口：无社区创建接口，社区不足阻塞。单 XML 不能控制跨任务停止调度，清理失败或未确认时，调度方必须停止后续任务及共享身份复用；身份必须串行执行。
- 仅生成和离线校验，未运行 HTTP、部署或修改数据库。

- 实现观察（仅静态读取，未执行）：RoomsControllerImpl.markRoomRead 直接构造成功 ReadPosition，未调用 authorization() 或成员校验；因此当前版本可能在目标 403/40301 断言处失败。保持源期待，不将实现的 200 回显作为通过。
