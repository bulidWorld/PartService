# 用例 079 生成说明

- 六位随机数字验证码：compute 无随机数字函数，code 固定为 "123456"（测试环境已关闭邮箱验证码校验，见 md 执行约定）。
- 昵称 "测+UUID去连字符前12位"：无 substring 函数，改为固定昵称 测079甲/测079乙（昵称允许重复）。
- 收件查询 "每秒重试最多 30 秒"：GET /topics/receipts 使用 poll maxAttempts="30" intervalMilliseconds="1000" timeoutSeconds="30"。
- md 步骤 10 的 "重复到空页或 hasMore=false、最多10页" 是循环，XSD 无循环节点：展开为 4 次固定请求（limit=1 首页 + before=oldest/oldest2/oldest3 三页），首页提取 oldest，逐页提取 next 并断言恰好一项且其 id 属于 {M1,M2,M3}、与已见页互斥（不重复）、空页断言 items 为空且 hasMore=false；本用例只有 3 条消息，4 页覆盖全部并落在 10 页上界内。
- "合并页后恰为 M1/M2/M3、同秒消息不遗漏" 通过逐页归属+互斥断言等价表达（每页唯一消息必属 {M1,M2,M3} 且不重复，空页终止），不依赖服务端排序方向。
- 清理中 "GET /rooms 按主题 ID 筛选补录 roomId"：extract 表达式不支持按谓词筛选列表元素，无法表达；改为 SQL 清理步骤以 ifParameter="r" 跳过保护，accept 失败未取得 roomId 时聊天室可能残留。
- 保留行为断言：全部账号注销后无有效令牌，无法 HTTP 断言，故放在注销 B（成员）之后、注销 A（发布者）之前，用 A 令牌断言房间保留（topicId=T）、B 已从 members 移除、消息 M1 仍可读。
- SQL 表名已按 src/main/resources/db/03-chat.xml 核实：chat_room（外键级联删除 chat_message/chat_message_read/chat_member）。
