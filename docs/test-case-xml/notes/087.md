# TC-087 转换说明

- 来源：`docs/test-case/087-chat-client-id-boundary.md`；生成 `087-chat-client-id-boundary.xml`。仅生成及离线校验，未发送 HTTP、部署或修改数据库。
- 独立准备完整保留：查询社区、A/B 分别邮箱和不同手机号注册、创建主题、邀请、接受邀请；ROOM 校验为非空 UUID。用户 ID、访问及刷新令牌在注册响应立即提取，断言失败仍保存供 finally 清理。
- 业务覆盖：发送源文档恰好 64 个 ASCII m 的 clientMessageId、messageType=text、content=大家好，准时集合。、contentMeta={}；要求真实 HTTP 200、code=0、非空 requestId，响应逐字保留 clientMessageId 并明确检查长度为 64，同时保存消息 ID 和创建时间。
- 后续由 B 使用公开 GET /rooms/{roomId}/messages 查询历史，要求 HTTP 200、code=0、对应消息唯一，ID、聊天室、发送者、64 字符 clientMessageId、类型、内容、元数据、创建时间均与发送结果一致，recalled=false；本独立新聊天室 hasMore=false、nextCursor=null。
- finally 按 B、A 各自 GET /me 探测；过期返回 40101 时以本人刷新令牌恢复并更新清理凭证，然后 DELETE /me，要求 HTTP 200、code=0、data={}、非空 requestId。分别核查原始及当前访问/刷新令牌全部 HTTP 401、code=40101。单用户失败不阻断另一个用户清理；注销业务码及 requestId 单独提取，运行记录须脱敏。
- HTTP 前提缺口：当前 UsersControllerImpl.listCommunities 固定返回空列表，公开 HTTP 没有创建社区接口；运行将明确 Blocked，社区前提补齐前不能声称业务已验证。不存在此边界值的 HTTP 契约表达缺口，MessageRequest.clientMessageId 的 maxLength=64 允许正常 body 绑定。
- XSD/执行器缺口：单 XML 无法跨任务停止调度；共享邮箱和手机号必须串行执行。清理失败、响应丢失或凭证不足时须记录“清理失败/未确认”并停止环境复用，不能仅以 401 推断账号已删除。仅覆盖公开 HTTP 可观察结果，不声称验证内部存储、广播或日志。
- 校验：validate.py 为 1 XML / 0 errors；validate_importer.py --importer-root /opt/apps/Deployment/AutoTestService 为 1 XML / 0 errors。真实导入器离线转换及配置验证，不连接 DB/HTTP。
