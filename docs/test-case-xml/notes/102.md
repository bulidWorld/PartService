# 用例 102 生成说明
- communityChangedAt 格式断言用逐字符手工校验 YYYY-MM-DDTHH:mm:ssZ（断言沙箱禁 re，无正则可用）
- X-Request-Id 通过 header value="{request}" 引用任务级 generateUUID() 参数（header 无 parameter 子元素，只能用 {名} 引用）
- 昵称按 md 规则“测+UUID 前 12 位”需要 substring，XSD 无此函数 → 固定昵称“测102甲”
- 验证码 code 固定 "123456"（环境已关闭注册验证码校验）
- 服务端 JacksonConfig 已配置秒精度 ISO-8601（appendInstant(0)），与 md 期望格式一致
