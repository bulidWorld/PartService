# TC-050 转换记录

- 保留独立社区查询、邮箱注册、主题创建、发布者 PATCH、后续 GET 和 finally 清理。创建响应保存主题 ID、publisherId、communityId、createdAt；PATCH 与 GET 均检查上述字段不变，及标题、详情、18/60 年龄约束、male/female 性别集合保存正确。PATCH 同时提交 title/detail，符合 TopicRequest。
- 所有 REST 显式鉴权并检查真实 HTTP 状态与业务码；准备失败或缺社区标记 Blocked，不将准备请求视为业务通过。注册断言失败仍提取创建账号及全部凭证。
- 清理先 GET /me 探测，仅 40101 时刷新并更新清理令牌；DELETE /me 必须 HTTP 200、code=0、data={}、非空 requestId。随后分别检查原始和当前访问/刷新令牌 HTTP 401、code=40101。敏感令牌不应保存原文。
- HTTP 缺口：没有创建社区接口，社区不足只能 Blocked；目标业务无未覆盖范围。不推断数据库、日志或广播。
- XSD/执行范围缺口：单 XML 无法保证跨任务身份互斥、清理失败停止后续调度、环境初态或持久化脱敏执行记录；执行者须串行复用邮箱并落实这些策略。清理响应异常或凭证缺失须记未确认，不能以 401 推断已注销。
- 使用现存 docs/test-case-xml/task.xsd；不恢复已删除源 XSD。只生成和离线校验，不运行 HTTP、不部署、不改数据库。
