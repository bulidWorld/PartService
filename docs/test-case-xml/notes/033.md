# TC-033 转换说明

- 来源：`docs/test-case/033-community-inactive.md`；产物：`033-community-inactive.xml`。
- 保留源用例唯一公开 HTTP 调用 `GET /communities`，明确无鉴权、Accept JSON，核查 HTTP 200、业务码 0 和社区数组后抛出 `Blocked`。查询准备失败同样阻塞；查询成功不代表目标场景通过。
- HTTP 接口缺口：`users.yaml` 仅有社区列表以及用户切换接口，没有创建、停用或查询停用状态接口；无法独立获得确认停用的目标社区，故无法验证“切换被拒绝、原社区不变”。未猜测 ID、未注册账号、未发送切换请求，无数据变更和清理需求。
- 实现参考：`UsersControllerImpl.listCommunities` 当前返回空列表；`changeCommunity` 当前未显式核查目标社区启用状态。这是静态观察，不作为 HTTP 实测结果或缺陷复现。
- XSD 缺口：现存 `docs/test-case-xml/task.xsd` 的四参数断言及 `Blocked` 已能准确表达此阻塞流程，无本用例特有表达缺口。用户指定的 `docs/task.xsd` 当前不存在，采用现存 XSD。跨任务“清理失败停止后续用例”由执行器调度实现，单任务 XSD 无此配置；本用例只读，无清理失败路径。
- 仅离线生成和校验，未运行 HTTP。断言使用执行器白名单支持的 `isinstance`、`dict`、`list` 和常规字典方法。
