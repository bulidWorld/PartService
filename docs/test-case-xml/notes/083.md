- 来源：`docs/test-case/083-chat-empty-text.md`；生成 `083-chat-empty-text.xml`。仅生成及离线校验，未发送 HTTP、部署或修改数据库。
- 完整独立准备：查询社区、A/B 注册、创建主题、邀请及接受邀请，校验 ROOM 非空 UUID。注册立即提取用户 ID、访问及刷新令牌；即使断言失败也发布凭证用于 finally。
- 业务覆盖：A 发送 clientMessageId=empty-text、messageType=text、content 空字符串、contentMeta={}，要求真实 HTTP 400、code=40001；B 查询 limit=20 的消息历史，要求 HTTP 200、code=0、items=[]、无后页。
- finally 按 B、A 分别 GET /me 探测；仅过期时刷新并更新当前凭证，DELETE /me 检查 HTTP 200、code=0、data={}、非空 requestId；逐一核查注册及刷新签发的新旧访问/刷新令牌均 HTTP 401、code=40101。单步清理失败继续后续清理，保留注销业务码及 requestId，执行记录须脱敏。
- 前提缺口：当前 UsersControllerImpl.listCommunities 固定返回空列表，且无创建社区 HTTP 接口，执行时将明确 Blocked；不能把社区查询成功计作空文本场景通过。完整业务流程已编码，但在前提补齐前尚未执行覆盖。
- HTTP 契约 MessageRequest.content 没有 minLength，结构化空字符串可直接导入，无需 rawBody；发送失败码未列入 OpenAPI responses，依据源用例明确断言，未放宽要求。仅覆盖可观察 HTTP，不声称验证广播、内部存储或日志。
- XSD/执行器缺口：单 XML 无法控制跨任务停止调度。共享邮箱及手机号必须串行复用，任何用户清理失败/未确认时执行方须停止后续环境复用。创建成功但响应丢失或凭证不足无法确认清理时，必须记录清理未确认，不能仅凭 401 推断已注销。
- 校验：validate.py：1 XML / 0 errors；validate_importer.py --importer-root /opt/apps/Deployment/AutoTestService：1 XML / 0 errors。真实导入器离线转换及配置校验，不连接 DB/HTTP。
