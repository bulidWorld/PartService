# TC-071 转换说明

- 来源：`docs/test-case/071-invitation-accepted-reject.md`。独立读取社区、注册 A/B、创建主题、邀请并接受；接受响应必须 HTTP 200/code=0、accepted，ROOM 为非空 UUID。全部变量来自本文件前序响应。
- 接受后拒绝允许 HTTP 200/code=0 且仍返回同一个 accepted 邀请/聊天室，或 HTTP 409/code=40901 并有非空错误消息（业务冲突码依据 ApiException.conflict）。随后以 B 查询聊天室，核查 ROOM/T/所有者及成员恰为 A/B；额外以 B 查询邀请列表，无后页且该主题恰一个邀请，仍为 I/accepted/ROOM，避免仅凭冲突响应宣称终态不变。
- 社区不足、注册或主题准备失败明确 Blocked；不把准备查询通过冒充目标通过。当前社区实现返回空列表，实际执行可能因此阻塞。注册断言失败仍提取用户 ID 和全部凭证，finally 按 B/A 清理。
- finally 对每个已创建用户探测 /me，过期时刷新更新凭证，DELETE /me 要求 HTTP 200/code=0/data={} 及非空 requestId；逐项验证原始及最新访问/刷新令牌 HTTP 401/code=40101。单步失败仍尝试后续清理，提取注销业务码及 requestId；真实 HTTP 结果由执行器记录。401 本身不能证明账号已删除。
- 未覆盖内部存储/广播/日志，源用例仅要求公开 HTTP 可观察结果。接口足够覆盖目标，无需捏造接口。OpenAPI 未列拒绝接口 409、/me GET 和 refresh 的 401 响应，按源要求及实现明确校验 HTTP/业务码；XSD 可表达本流程。
- 清理失败跨任务停止调度无法由单 XML 表达；外部执行器必须串行复用共享身份，任何清理失败或未确认都停止环境复用。执行记录脱敏，不保存令牌原文。
- 仅生成并进行 XSD/语义及真实导入器离线转换/配置校验；未执行 HTTP、部署或数据库操作。
