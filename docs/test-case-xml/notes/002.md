# 用例 002 生成说明
- 六位随机数字验证码：compute 无随机数字函数，code 固定为 "123456"（环境已关闭验证码校验）。
- 昵称按 md 规则应为 UUID 去连字符前 12 位，XSD 无 substring，改用固定昵称 "测002甲"。
- 邮箱用 compute 的 concat 拼接 run（任务级 generateUUID()）实现 tc-${run}-a@example.com。
- 本例未创建主题，故 md 清理模板中的 GET /rooms 补录与 DELETE FROM chat_room 清理无对象，finally 仅注销 A（DELETE /me）并验证令牌失效（GET /me 401/40101）。
