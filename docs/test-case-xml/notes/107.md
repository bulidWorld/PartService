# 用例 107 生成说明

- `run` 运行时生成；A/B 邮箱基于 run 拼接，账号互不冲突。
- 本地开发的 `send-code` stub 固定发送 `000000`，用它完成注册验证码校验；真实验证码环境应改为读取测试专用验证码，不复用该值。
- B 使用手机号 `139000000099`；运行前确认未占用，账号清理后该身份会释放。
- 所有密码参数标记 sensitive；注册响应 access token 用于 finally 注销，A、B 分别登记清理。
- 改密成功后验证 A 新密码可登录、旧密码失效；B 持自己的 bearer token 提交 A 的旧密码改密失败，随后 A 的新密码仍可用。
