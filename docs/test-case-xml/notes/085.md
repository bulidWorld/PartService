# TC-085 转换说明

- 源：`docs/test-case/085-chat-unknown-type.md`；生成同 stem XML。覆盖独立社区查询、双用户注册、创建主题、邀请/接受、发送未知类型 HTTP 400/code=40001，以及接收方消息历史为空。ROOM 检查非空 UUID；全部 REST 显式鉴权并断言真实 HTTP/业务码。
- HTTP 契约具备所需接口；messageType 为未限定枚举的 string，`video_unknown` 可用结构化 body，无需 rawBody。当前 OpenAPI 未声明发送消息 400 响应及大部分 401 响应，XML 仍明确断言源用例要求的状态和业务码，不修改契约。
- 当前 `UsersControllerImpl.listCommunities()` 固定返回空数组，且没有公开创建社区接口。执行时社区不足明确 Blocked，不伪造社区或把查询成功当目标通过。此时未知类型和历史核查未覆盖；仅可在已有测试环境公开接口提供社区后执行完整链路。
- 注册响应立即提取用户 ID/访问/刷新令牌，即使断言失败仍发布；finally 先 B 后 A，探测令牌过期、必要时刷新、DELETE /me，并检查本用例原始和当前全部访问/刷新令牌失效。单用户失败不阻止其他用户清理；凭证失效不能推断账号已删除。
- 单 XML 无跨任务停调度/共享身份锁能力。执行者须串行复用邮箱/手机号；记录脱敏 HTTP/业务码、requestId 和逐用户清理结论，清理失败或未确认则停止后续任务并停止复用环境。不验证内部存储、广播或日志。
- 仅生成与离线校验；未执行 HTTP、未部署、未改数据库。
- 校验结果：`validate.py` 1 XML / 0 errors；`validate_importer.py --importer-root /opt/apps/Deployment/AutoTestService` 1 XML / 0 errors（真实导入器离线转换和配置检查）。
